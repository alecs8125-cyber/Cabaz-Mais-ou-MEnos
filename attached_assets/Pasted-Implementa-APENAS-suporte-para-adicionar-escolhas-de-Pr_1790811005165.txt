ESTADO ATUAL CONFIRMADO:

- A Home lê product_groups ativos.
- É possível selecionar:
  tipo → variante → formato.
- Depois são carregados apenas os produtos ativos associados ao group_id.
- Existe:
  "Qualquer marca"
  ou uma marca específica.
- "Qualquer marca" fica semanticamente:
  groupId + brand null.
- Uma marca específica fica:
  groupId + brand.
- Nenhuma seleção genérica tem product_id.
- Produtos exatos continuam a funcionar.
- TypeScript passou.
- 83 testes passaram, 0 falharam.

OBJETIVO:

Permitir adicionar ao cabaz uma escolha genérica como:

Leite Meio-Gordo 1 L
Qualquer marca

OU:

Leite Meio-Gordo 1 L
Mimosa

SEM transformar essa escolha num produto fictício.

-----------------------------------
1. PRESERVAR LINHAS EXATAS
-----------------------------------

O sistema atual de produtos exatos deve continuar a funcionar.

Uma linha exata continua semanticamente equivalente a:

{
  kind: 'exact',
  productId: '...',
  quantity: 1
}

Não é obrigatório alterar imediatamente todos os objetos antigos para
terem kind: 'exact'.

IMPORTANTE:

Objetos antigos sem "kind" devem continuar a ser interpretados como
produtos exatos.

Não fazer migração destrutiva.

-----------------------------------
2. NOVA LINHA GENÉRICA
-----------------------------------

Adicionar um tipo explícito para linha genérica.

Semanticamente:

{
  kind: 'group',
  groupId: '...',
  groupName: 'Leite Meio-Gordo 1 L',
  brand: null,
  quantity: 1
}

Para marca específica:

{
  kind: 'group',
  groupId: '...',
  groupName: 'Leite Meio-Gordo 1 L',
  brand: 'mimosa',
  brandLabel: 'MIMOSA',
  quantity: 1
}

A implementação pode adaptar os nomes ao código atual.

REGRAS:

- groupId é obrigatório;
- não criar productId;
- não criar produto fictício;
- não criar preço fictício;
- guardar informação suficiente para apresentar a linha sem precisar
  consultar novamente o catálogo;
- preservar o texto visual da marca quando disponível.

-----------------------------------
3. IDENTIDADE DA LINHA
-----------------------------------

Produtos exatos continuam identificados por productId.

Linhas genéricas devem ser identificadas por:

groupId + brand

Assim:

Leite Meio-Gordo 1 L · Qualquer marca

e

Leite Meio-Gordo 1 L · Mimosa

são duas linhas diferentes.

Adicionar novamente exatamente a mesma combinação deve aumentar a
quantidade da linha existente, e não criar duplicado.

-----------------------------------
4. BASKETCONTEXT
-----------------------------------

Adaptar BasketContext e os helpers necessários para aceitarem:

- linhas exatas existentes;
- linhas genéricas novas.

Preservar:
- adicionar;
- aumentar quantidade;
- diminuir quantidade;
- remover;
- limpar cabaz.

Não quebrar o comportamento atual dos produtos exatos.
