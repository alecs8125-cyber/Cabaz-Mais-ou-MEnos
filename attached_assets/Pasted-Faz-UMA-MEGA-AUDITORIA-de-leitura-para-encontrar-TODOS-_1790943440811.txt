--------------------------------
REGRA PRINCIPAL
--------------------------------

Um ProductGroup só pode ser classificado como:

SEGURO PARA CRIAR

quando tiver PELO MENOS 5 produtos realmente equivalentes.

Os produtos devem ter:

- mesmo tipo;
- mesma variante relevante;
- mesma quantidade;
- mesma unidade;
- finalidade equivalente.

Usar:

- id
- name
- brand
- category
- barcode
- package_quantity
- package_unit
- unit
- active

Apenas products.active = true.

--------------------------------
NÃO MISTURAR
--------------------------------

Não misturar automaticamente:

- normal com Bio/Organic;
- normal com light;
- normal com zero;
- normal com sem açúcar;
- normal com sem lactose;
- normal com sem glúten;
- normal com integral;
- sabores diferentes;
- percentagens diferentes quando forem relevantes;
- peso total com peso escorrido;
- seco com cozido/enlatado;
- líquido com sólido;
- multipacks diferentes;
- tamanhos diferentes;
- produtos preparados com produto simples;
- cortes diferentes de carne/peixe;
- embalagens individuais com caixas/familiares.

Não usar apenas a marca para decidir equivalência.

--------------------------------
FORMATOS
--------------------------------

Normalizar apenas quando for matematicamente equivalente:

- 1 L = 1000 ml
- 0,5 L = 500 ml
- 1 kg = 1000 g

Não assumir equivalência quando houver dúvida.
